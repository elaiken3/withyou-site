# Support

Thanks for using WithYou. There’s no wrong way to use it, and there’s no wrong question.

## Get help or report a bug

Open an issue on GitHub: [github.com/elaiken3/withyou/issues](https://github.com/elaiken3/withyou/issues). There are templates for bug reports, feature ideas and UX feedback.

If you’re testing through TestFlight, you can also use **Send Feedback** in the TestFlight app. Taking a screenshot in WithYou opens the same feedback form.

## What helps us fix things

- Your iPhone model and iOS version
- The WithYou version (shown in TestFlight)
- What you expected to happen, and what happened instead
- Steps to reproduce it, if you can
- A screenshot or screen recording, if you have one

Please don’t include personal content, like your captured thoughts or tasks, in public issues.

## Feedback we especially want

You’re not testing productivity. You’re testing emotional load. Tell us:

- where you felt relief,
- where friction remained,
- anything that felt unintentionally pressuring, and
- whether the language felt safe.
